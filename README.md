# RemontHouseRoom — демо-сайт

Одностраничный сайт компании по ремонту квартир и санузлов в Подольске.
Next.js, Tailwind и ИИ-консультант, который отвечает по услугам и заполняет
заявку за посетителя.

## Дизайн

Визуальное решение собрано по скиллу [ui-ux-pro-max](https://github.com/nextlevelbuilder/ui-ux-pro-max-skill):

- паттерн **Trust & Authority + Conversion** — первый экран с доверием,
  сразу за ним блок подтверждений, потом услуги и путь к заявке;
- стиль **Flat Design** — без теней и градиентов, глубину даёт граница,
  переходы 180 мс;
- палитра: синий `#1E40AF` держит доверие, оранжевый `#EA580C` отмечает
  единственное действие — связаться;
- шрифты **Playfair Display** (заголовки) и **Inter** (текст);
- иконки — свой штриховой набор в `src/components/Icon.tsx`, эмодзи вместо
  иконок скилл запрещает.

## Запуск

```bash
npm install
cp .env.example .env.local   # ключ нужен только для консультанта
npm run dev                  # http://localhost:3000
```

Без `ANTHROPIC_API_KEY` сайт, галерея и форма работают полностью, а чат честно
отвечает, что консультант недоступен, и даёт номер.

## Где что лежит

| Что | Где |
| --- | --- |
| Контакты, часы, рейтинг, ссылки на мессенджеры | `src/lib/company.ts` |
| Услуги, цены, этапы, отзывы, галерея | `src/lib/services.ts` |
| Промпт и инструменты консультанта | `src/lib/ai.ts` |
| Поток ответа консультанта | `src/app/api/chat/route.ts` |
| Секции страницы | `src/components` |
| Картинки галереи | `public/works` |

Телефон, адрес и часы заданы в одном месте — шапка, футер, кнопки WhatsApp,
разметка для карт и промпт ИИ читают их оттуда. Разъехаться им негде.

## Как заменить фотографии

Сейчас в `public/works` лежат восемь SVG-заглушек. Положите на их место
настоящие снимки с теми же именами (`.jpg` тоже подойдёт — тогда поправьте
расширения в `WORKS` в `src/lib/services.ts`) — верстка не изменится.

Когда заглушек не останется, из `next.config.ts` можно убрать
`dangerouslyAllowSVG`, а из `Works.tsx` — строку о том, что фотографии
демонстрационные.

## Что умеет консультант

Отвечает по услугам, двум известным ценам, этапам работ, адресу и часам.
Кроме ответов у него два инструмента:

- `show_section` — прокручивает страницу к нужному разделу;
- `prefill_request` — заполняет форму заявки (услуга, площадь, комментарий)
  и подсвечивает её.

Заявку он не отправляет: форма собирает сообщение и открывает WhatsApp, где
человек отправляет его сам. Никаких «заявка принята» без реальной заявки.

Модель по умолчанию — `claude-haiku-4-5`, ради скорости ответа. Меняется
переменной `ANTHROPIC_MODEL`.

## Откуда данные и что проверить у владельца

Все сведения взяты из карточки компании на Яндекс Картах. Проверить до показа
клиенту:

1. **Телефон и название.** Тот же номер встречается на сайте «Лето Климат».
   Возможно, это общий номер, старый бренд или ошибка справочника.
2. **Цены.** Карточка отмечает, что данные давно не обновлялись. На сайте обе
   цены даны с пометкой «ориентировочно».
3. **Рейтинг.** В карточке 4,5 и 9 оценок. Сторонние каталоги показывают
   другие числа (например, 59 оценок) — на сайте стоят данные карточки.
4. **Спорные услуги.** В карточке есть метки про каркасные дома, свайный
   фундамент, гаражи, промышленные полы и гидротехнические сооружения. На сайт
   они не вынесены: сначала пусть владелец подтвердит, что компания это делает.

Чего на сайте нет намеренно, потому что это не подтверждено: гарантия, стаж,
количество объектов, бесплатный замер, цена за квадратный метр, сроки в днях,
работа по Москве и области, дизайн-проекты, закупка материалов, юридическое
название. Всё это легко добавить в `src/lib`, когда владелец даст цифры.

## Деплой

Обычное приложение Next.js: Vercel, Docker, любой хостинг с Node. Для
консультанта на хостинге нужна переменная `ANTHROPIC_API_KEY`.
